# OpenAI-compatible provider adapter v1

Canonical owner: [#471](https://github.com/RepairYourTech/SymbioteIDE/issues/471), depending on #464. `symbiote-provider-openai` is the first `InferenceProviderAdapter` behind the neutral provider contract `symbiote-runtime-sdk::provider` defines: the wire format lives here and nowhere else, so provider shapes stay out of orchestration. This is not #471's full acceptance — no live provider enablement, no streaming transport over a held-open connection, no image-bearing requests — and those remain explicitly pending, gated on AUTH-01 evidence and the operator's authorization for live turns.

## Capability catalog

The catalog is a versioned document: `catalog_version: 1`, one entry per model carrying the model's context-window bound, output bound, supported reasoning efforts, and whether it declares tools. The reader refuses a document whose version it does not speak, whose bounds are zero or inverted, or which names one model twice. `authorize` is the pre-inference gate the transport consults before its first byte, and it refuses rather than coerces: an effort the entry does not name is refused (`unsupported_capability`), never downgraded to the nearest one; an output budget past the entry's bound is `output_limit`; an input estimate past the context window is `context_limit`; tools requested of a model that declares none are `unsupported_capability`; a model the catalog does not hold is `model_mismatch` — which is also how a request built against a changed catalog fails, by name, when the connection's models moved. A catalog entry must not promise less than the `ModelDescriptor` it stands beside, and `holds` says so.

## Wire mapping

The neutral request encodes as the provider's chat-completions JSON: messages in order, tools in function form, the output budget as `max_tokens`, the effort as `reasoning_effort` when requested, and `stream_options.include_usage` when streaming. Image parts ride artifact references the Host resolved; this text-only adapter leaves them out of the encoding rather than guessing a provider shape for them, and states that boundary here. Decoding maps `stop`, `tool_calls` and `length`; a finish reason the adapter does not recognize is an envelope refused, because a finish reason nobody named is a contract the provider changed. Tool-call ids become `RequestId`s — the neutral vocabulary bounds what an id is, and a call whose id is not one is refused. Streaming is a `StreamAssembler`: text and tool-call argument fragments accumulate per index until the provider names its finish reason, and duplicate call ids are the duplicate they are.

Usage preserves the provider's semantics: prompt and completion totals stand as reported, the cached subset rides beside input and the reasoning subset beside output, neither counted into the totals, and the crate's own `total()` refuses a subset that outruns its total. A response without a usage object — whole or streamed — decodes to `TokenUsage::Unknown` with the reason it is unknown, never to a zero.

## Transport and trust

One endpoint, exactly allowlisted by host (exact match; no suffix rule, so `api.example.com.evil.test` passes nothing), one credential supplied per request through a source the adapter never logs or serializes, one wall-clock deadline the whole request is held to. Redirects are refused, never followed — any 3xx is `local_policy_required`, so a credential cannot be walked to another origin while the adapter believes it is still where it was pointed. Statuses classify into the neutral payload-free vocabulary: 401 and 403 are `credential_required`; 408, 429, 500, 502, 503 and 504 are `unavailable`, the rate-limit case among them; the rest are the provider refusing the request's own terms. The provider's error prose is dropped with its status.

A stream cut before its finish reason is `unavailable`, never an assembled completion: an interrupted generation is not a completed one, and a partial answer handed to the loop as a whole one is how a retried run re-executes a tool the first attempt already committed. Local endpoint support is protocol-tested in this crate against an in-process server; it is not assumed from an OpenAI-compatible label. No live provider is contacted by these tests, and live enablement depends on AUTH-01, not this crate.

## Bounds this adapter enforces

The neutral contract's envelope bound of 256 KiB bounds every request this transport writes and every response it accepts, and `catalog version 1` is the only catalog document this reader speaks. The deadline is the operator's configuration, not a published constant. Redirects are refused, and a refusal is always by name from the neutral vocabulary — never a message the provider wrote.
